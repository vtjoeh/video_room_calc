# Codex context

The shared project context menu is [`.ai/README.md`](../.ai/README.md). Read it
and the relevant project references before work. Store project-specific
knowledge in `.ai/` or the existing canonical reference, not in this file.

This file is reserved for Codex operation and environment-specific
instructions. Preserve Codex-only configuration in `.codex/` (for example,
`.codex/config.toml`). Repository instructions are entered through
[`AGENTS.md`](../AGENTS.md). The floor-plan task workflow is shared at
[`.ai/workflows/floorplan-to-vrc.md`](../.ai/workflows/floorplan-to-vrc.md).

If unsure whether new guidance is tool-specific or project-specific, ask the
user before adding it. Do not create developer profiles or retain personal
preferences.
