# Video Room Calculator

**Video Room Calculator for Cisco video devices by Joe Hughes** (beta)

A free, web-based tool for designing Cisco video collaboration room layouts. Place equipment (cameras, microphones, displays, tables, chairs) on a 2D canvas, model single or multi-room floor plans, and export directly to Cisco's Workspace Designer for 3D visualization. Everything runs client-side in your browser — no account, no server, no data collection. Save your design as a shareable link or a `.vrc.json` file.
